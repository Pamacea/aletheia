# Aletheia

> **« La philosophie ne sert pas à transformer le monde, mais à se transformer soi-même »**

**Aletheia** (ἀλήθεια) — *Vérité, dévoilement* en grec ancien. C'est le moment où l'être se révèle, où ce qui était caché apparaît en pleine lumière.

---

## Pourquoi Aletheia ?

Nous vivons à une époque de surinformation. Nous avons accès à tout le savoir du monde, mais nous manquons de **sagesse**.

**2500 ans de pensée humaine** ont produit les outils pour comprendre :
- Qu'est-ce que le bonheur ? (Épicure, Aristote)
- Comment vivre libre ? (Sartre, Spinoza)
- Qu'est-ce que la vérité ? (Platon, Heidegger, Descartes)
- Comment bien agir ? (Kant, Bentham)

**Ces questions ne sont pas des abstractions.** Elles sont les fondements de chaque décision que vous prenez, chaque relation que vous construisez, chaque choix de vie.

Aletheia n'est pas une encyclopédie. C'est un **outil d'appropriation** — pour que la philosophie ne reste pas un savoir mort, mais devienne une **pratique vivante**.

---

## Ce qu'Aletheia vous offre

- **Graphe de connaissances** — Visualisez comment les idées se répondent à travers les siècles. Platon converse avec Kant. Épicure dialoguent avec Nietzsche.
- **Système de répétition espacée** — La sagesse s'oublie si on ne l'entretient pas. Aletheia planifie vos révisions au moment optimal.
- **Annotations personnelles** — La pensée philosophique n'est pas dogmatique. Ajoutez votre voix à celle des maîtres.
- **Parcours guidés** — Entrez dans un courant (Stoïcisme, Existentialisme...) et suivez le fil de la pensée.

## Quick Start

```bash
git clone <repo-url> && cd aletheia
npm install
npm run dev && npm run db:seed
```

Ouvrez [localhost:3000](http://localhost:3000) — commencez votre voyage.

---

## L'esprit du projet

**Aletheia est construit différemment :**

- **Pas d'algorithmes addictifs** — Vous décidez de votre parcours, pas une IA qui optimise votre temps d'attention
- **Contenu ouvert** — Les textes philosophiques appartiennent à tous
- **Design apaisé** — Une interface qui invite à la réflexion, pas à la dopamine
- **Vos données sont à vous** — Pas de tracking, pas de publicité

La philosophie n'est pas un luxe. C'est une **nécessité** pour tout être humain qui veut comprendre sa place dans le monde.
